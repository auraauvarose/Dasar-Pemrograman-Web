📚 Rangkuman Teori: Pendahuluan Web

Memahami konsep dasar sebelum menulis kode HTML dan CSS

1. Pengantar Web Programming

Web Programming adalah proses menulis instruksi (kode) yang dijalankan oleh komputer untuk membuat halaman web dapat diakses dan interaktif.

Tiga Pilar Web:
  • HTML: Kerangka & struktur konten (Tulang).
  • CSS: Desain & tampilan visual (Baju/Kulit).
  • Javascript: Logika & interaktivitas (Otot/Otak).

2. Cara Internet Bekerja

Internet adalah jaringan global komputer raksasa yang saling terhubung satu sama lain.

Alur Singkat Request Web:
  1. Kamu mengetik URL (misal: google.com) di browser.
  2. Browser meminta bantuan DNS (Domain Name System) untuk menerjemahkan nama domain ke alamat IP (seperti buku telepon internet).
  3. Browser mengirimkan HTTP Request ke Web Server menggunakan alamat IP tersebut.
  4. Web Server memproses permintaan dan mengirimkan kembali HTTP Response berisi berkas HTML/CSS/JS.

3. Website & Jenis Halaman Web

Website adalah kumpulan dari halaman-halaman web yang saling terhubung di bawah satu nama domain.

Web Statis
  • Kontennya tetap (tidak berubah-ubah).
  • Dibuat hanya dengan HTML dan CSS.
  • Contoh: Web portofolio, landing page produk sederhana.
Web Dinamis
  • Konten berubah-ubah secara realtime (tergantung database/user).
  • Menggunakan Javascript, PHP, Python, Database.
  • Contoh: Social Media (Facebook), E-commerce.

4. Web Server & Web Browser

Web Server: Komputer khusus yang menyimpan file website (HTML, CSS, JS) dan bertugas mendengarkan serta merespon permintaan dari komputer lain (klien) lewat internet.

Web Browser: Aplikasi di perangkat kita (seperti Chrome, Firefox, Safari) yang bertugas membaca kode HTML/CSS/JS dari server dan menerjemahkannya menjadi tampilan visual yang kita lihat.

5. Anatomi Layout Website

Umumnya, halaman website memiliki struktur tata letak dasar sebagai berikut:

Header (Judul, Logo, Navigasi Menu)
Main Content (Artikel, Konten Utama)
Sidebar (Menu Samping, Widget, Iklan)
Footer (Hak Cipta, Kontak, Link Sosial Media)
