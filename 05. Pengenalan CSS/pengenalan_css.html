🎨 Pengenalan CSS (Cascading Style Sheets)

Memahami sintaks, aturan, dan cara melampirkan styling pada dokumen HTML

📚 Rangkuman Materi

1. Apa itu CSS?

CSS (Cascading Style Sheets) adalah bahasa pemrograman yang digunakan untuk mengatur tampilan visual dan tata letak halaman web. Dengan CSS, kita bisa memisahkan konten (HTML) dari penyajian visualnya (CSS) sehingga kode menjadi lebih rapi dan mudah dirawat.

2. Anatomi Aturan CSS (Rule Set)

Aturan styling CSS ditulis dengan susunan berikut:

h1 { color: blue; font-size: 12px; }
  • Selector (Penyeleksi): Elemen HTML yang ingin diberi gaya (contoh: h1).
  • Declaration Block (Blok Deklarasi): Dibungkus dengan kurung kurawal { }, berisi satu atau lebih deklarasi yang dipisahkan tanda titik koma (;).
  • Property (Properti): Jenis gaya yang ingin diubah (contoh: color, font-size).
  • Value (Nilai): Nilai baru yang diberikan untuk properti (contoh: blue, 12px).

3. Tiga Cara Melampirkan CSS

  • Inline CSS: Ditulis langsung di dalam tag HTML menggunakan atribut style="...". Sangat spesifik namun sulit dikelola secara massal.
  • Internal CSS: Ditulis di dalam tag <style> di bagian <head> halaman HTML.
  • External CSS: Ditulis pada file terpisah berformat `.css`, lalu dihubungkan menggunakan tag <link rel="stylesheet" href="..."> di dalam <head>. Ini merupakan cara terbaik dan paling direkomendasikan.
