Elemen Dasar: Paragraf, Heading, List & Gambar

📚 Rangkuman Teori

  • Paragraf (<p>): Tag block-level untuk menulis teks paragraf. Browser otomatis menambahkan ruang kosong (margin) sebelum dan sesudah elemen paragraf.
  • Heading (<h1> sampai <h6>): Mendefinisikan judul halaman atau bagian. <h1> adalah judul paling utama (terbesar) dan <h6> adalah judul paling rendah (terkecil).
  • Daftar (List):
    • Unordered List (<ul>): Daftar tidak berurutan (bullet points).
    • Ordered List (<ol>): Daftar berurutan (nomor/abjad). Menggunakan atribut type="..." untuk menentukan jenis penomoran (1, a, A, i, I).
    • Nested List: Daftar bersarang (memasukkan elemen list baru di dalam tag <li>).
  • Gambar (<img>): Elemen inline untuk menampilkan gambar. Tag ini bersifat *self-closing* (tidak butuh tag penutup). Atribut wajib:
    • src="...": Lokasi/URL gambar.
    • alt="...": Deskripsi alternatif gambar jika gagal dimuat (sangat penting untuk aksesibilitas/SEO).
