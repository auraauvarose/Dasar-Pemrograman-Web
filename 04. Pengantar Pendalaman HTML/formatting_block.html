Block Formatting Text

📚 Rangkuman Teori (Block-Level Elements)

  • Block-Level: Elemen yang selalu dimulai pada baris baru dan mengambil seluruh lebar layar yang tersedia (dari kiri ke kanan).
  • <blockquote>: Digunakan untuk menampilkan kutipan panjang. Secara default, browser akan memberikan margin kiri dan kanan pada elemen ini. Atribut cite dapat ditambahkan untuk melampirkan URL sumber kutipan.
  • <pre> (Preformatted Text): Digunakan untuk mempertahankan format teks asli. Karakter spasi, tab, dan baris baru (Enter) yang ditulis di editor kode akan ditampilkan persis sama di browser. Sering digunakan untuk menulis puisi, sajak, atau blok kode komputer.
  • <figure> & <figcaption>: Digunakan untuk membungkus konten media mandiri seperti gambar, foto, atau ilustrasi (<figure>), serta menyertakan teks keterangan/judul untuk media tersebut (<figcaption>).
