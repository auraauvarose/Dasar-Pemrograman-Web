Formatting Text: Inline Elements

📚 Rangkuman Teori

  • Anchor (<a>): Digunakan untuk membuat tautan (hyperlink). Atribut penting:
    • href: Alamat tujuan (URL, email `mailto:`, telepon `tel:`, atau ID internal `#`).
    • target="_blank": Membuka tautan di tab baru.
    • download: Mengunduh file dari tautan tersebut.
    • title: Menampilkan deskripsi melayang (tooltip).
  • Format Penekanan (Emphasis):
    • <em>: Memberikan penekanan teks (secara visual *italic* / miring).
    • <strong>: Memberikan penekanan kuat (secara visual **bold** / tebal).
    • <mark>: Menandai/menyorot teks (seperti memakai stabilo).
  • Lainnya:
    • <sub>: Membuat subscript (teks di bawah, misal: H2O).
    • <sup>: Membuat superscript (teks di atas, pangkat, misal: E=mc2).
    • <q>: Menambahkan kutipan pendek (ditandai dengan tanda petik dua ganda secara otomatis oleh browser).
    • <dfn>: Mendefinisikan istilah baru.
    • <cite>: Menyebutkan sumber kutipan (buku, website, dll.).
