Formulir HTML & Input User

📚 Rangkuman Teori Formulir

  • <form>: Elemen kontainer untuk mengumpulkan input pengguna. Atribut penting:
    • action="...": URL tujuan pengiriman data formulir.
    • method="...": Cara pengiriman data. get (lewat URL, tidak aman untuk data sensitif) atau post (dikirim secara tertutup, aman untuk data sensitif/besar).
  • <label>: Memberikan judul label keterangan pada kolom input. Menggunakan atribut for="..." yang nilainya harus sama dengan id pada elemen input yang dituju (meningkatkan aksesibilitas).
  • Atribut Validasi pada Input:
    • required: Kolom input wajib diisi sebelum form dikirim.
    • placeholder="...": Teks petunjuk abu-abu sebelum diisi.
    • value="...": Nilai awal (default) dari kolom input.
  • Jenis-jenis Tipe Input:
    • type="text": Input teks baris tunggal biasa.
    • type="email": Input email (memiliki validasi format email otomatis).
    • type="password": Karakter yang diketik akan disamarkan (bullet).
    • type="date": Pemilih tanggal kalender bawaan browser.
  • <textarea>: Input teks baris ganda (multi-line) untuk deskripsi panjang atau alamat.
