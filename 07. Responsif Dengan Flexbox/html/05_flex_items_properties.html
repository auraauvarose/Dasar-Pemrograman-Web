05. Properti pada Flex Items (Materi 05)

📚 Properti-Properti untuk Child Element (Flex Items)

  • order: [angka]: Mengubah urutan tampilan flex items tanpa merubah urutan kode HTML (default adalah 0. Semakin kecil nilainya, semakin awal dia diposisikan).
  • flex-grow: [angka]: Menentukan porsi pertumbuhan item untuk menghabiskan sisa ruang kosong dalam container (default adalah 0 / tidak tumbuh).
  • flex-shrink: [angka]: Menentukan porsi penyusutan item saat ukuran container menyempit dan tidak mencukupi (default adalah 1 / menyusut. Berikan nilai 0 jika tidak ingin item menciut).
  • flex-basis: [ukuran]: Menentukan ukuran dasar (lebar/tinggi) awal elemen sebelum didistribusikan sisa ruang container (default adalah auto).
  • align-self: auto | flex-start | flex-end | center | baseline | stretch: Mengubah perataan vertikal (Cross Axis) untuk SATU item tertentu saja (meng-override nilai align-items milik container).
