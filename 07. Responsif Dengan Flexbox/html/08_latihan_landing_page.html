08. Latihan: Membangun Landing Page Dicoding (Materi 08)

📚 Langkah Membangun Landing Page

  • Reset Box Model: Menetapkan box-sizing: border-box untuk semua elemen (*::before, *::after, *).
  • Navigasi Fleksibel: Menggunakan display: flex pada navbar container dengan justify-content: space-around dan align-items: center.
  • Kolom Konten Ganda: display: flex pada div.content untuk berjejer horizontal secara default (flex-direction: row).
  • Shorthand Flex: Menggunakan properti flex: 1 1; pada area deskripsi teks dan gambar agar membagi ruang secara proporsional.
  • Ikon Sosial Media Terapung: Menggunakan position: fixed; pada aside, dikombinasikan dengan properti logical positioning modern seperti inset-block: 0; dan inset-inline-end: 0;.

🛠️ Area Praktik (Halaman Desktop Landing Page)

Buka file css/08_latihan_landing_page.css. Ikuti langkah TODO untuk melengkapi kode CSS agar halaman landing page berjejer rapi secara horizontal pada layar desktop!
