10. Rangkuman Layout Responsif dengan Flexbox (Materi 10)

📝 Rangkuman Komprehensif Flexbox

Berikut adalah tabel ringkasan semua properti Flexbox yang telah kita pelajari:

Tipe Target Nama Properti Fungsi Utama Nilai Populer
Parent Element (Flex Container)
Container display Mengaktifkan mode flexbox flex, inline-flex
Container flex-direction Menentukan arah sumbu utama (Main Axis) row, column, row-reverse, column-reverse
Container flex-wrap Membungkus baris elemen anak nowrap, wrap, wrap-reverse
Container justify-content Meratakan item di Main Axis center, space-between, space-around, space-evenly
Container align-items Meratakan item di Cross Axis stretch, center, flex-start, flex-end
Container align-content Meratakan baris-baris (multiline) center, space-between, space-around, space-evenly
Container gap Memberi celah kosong antar item [nilai ukuran] (e.g. 10px, 1rem)
Child Element (Flex Items)
Items order Menyusun ulang urutan visual item [angka bulat] (e.g. -1, 0, 1)
Items flex-grow Mengembangkan ukuran item mengisi sisa ruang [angka tanpa satuan] (default 0)
Items flex-shrink Mengizinkan item untuk menciut jika sempit [angka tanpa satuan] (default 1)
Items flex-basis Ukuran dasar awal sebelum pembagian ruang [ukuran / auto] (e.g. 150px, 20%)
Items align-self Meratakan satu item secara individu flex-start, flex-end, center, stretch
