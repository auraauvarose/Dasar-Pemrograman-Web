03. Dasar-Dasar dan Terminologi Flexbox (Materi 03)

📚 Terminologi Penting Flexbox

Untuk memahami Flexbox, kita harus mengetahui anatomi dan sumbu arahnya:

  • Flex Container: Parent element yang diberi properti display: flex atau display: inline-flex.
  • Flex Items: Semua child element langsung dari Flex Container.
  • Main Axis: Sumbu utama alur penyusunan item (horizontal jika flex-direction: row, vertikal jika flex-direction: column).
  • Cross Axis: Sumbu yang arahnya tegak lurus (90 derajat) terhadap Main Axis.
  • Main-Start & Main-End: Titik awal dan akhir item dijajarkan pada Main Axis.
  • Cross-Start & Cross-End: Titik awal dan akhir item dijajarkan pada Cross Axis.
  • Main Size & Cross Size: Dimensi item (lebar/tinggi) sepanjang Main Axis dan Cross Axis.

🛠️ Area Praktik (Visualisasi Sumbu)

Ubah properti flex-direction: row; menjadi flex-direction: column; pada selector .flex-container di CSS untuk melihat perubahan arah Main Axis dan Cross Axis secara instan!

Cross Axis (Row) / Main Axis (Column) ↓
