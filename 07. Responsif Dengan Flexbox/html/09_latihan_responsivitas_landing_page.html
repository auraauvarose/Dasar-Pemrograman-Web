09. Meningkatkan Responsivitas pada Landing Page Dicoding (Materi 09)

📚 Poin Responsivitas dengan Flexbox

  • Meta Viewport: <meta name="viewport" content="width=device-width, initial-scale=1.0"> mutlak diperlukan agar media queries terbaca dengan benar di mobile.
  • Flex Direction Change: Mengubah flex-direction: row menjadi column pada container di bawah breakpoint tertentu agar elemen tersusun vertikal di layar sempit.
  • Flex Wrap: Mengaktifkan flex-wrap: wrap pada navigasi menu agar teks tautan yang meluap di layar sempit otomatis turun ke baris baru secara teratur.
  • Order Property: Menggunakan order: -1 pada elemen gambar agar di mobile gambar diposisikan di atas teks deskripsi (meskipun di HTML gambar ditulis setelah teks).

🛠️ Area Praktik (Simulasi Mobile Landing Page)

Buka file css/09_latihan_responsivitas_landing_page.css. Selesaikan bagian media query di bagian bawah file untuk mengubah tampilan desktop di bawah menjadi responsif saat disimulasikan di layar kecil!
