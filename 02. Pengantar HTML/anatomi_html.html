📄 Anatomi & Struktur Dasar HTML

Memahami bagaimana elemen HTML disusun dan dideklarasikan

📚 Rangkuman Materi

1. Apa itu HTML?

HTML (HyperText Markup Language) adalah bahasa markup standar yang digunakan untuk membuat struktur halaman web. HTML terdiri dari kumpulan elemen yang memberi tahu browser bagaimana konten harus ditampilkan.

2. Anatomi Elemen HTML

Elemen HTML biasanya terdiri dari tag pembuka, konten, dan tag penutup.

<p class="info">Ini adalah konten paragraf.</p>
  • Tag Pembuka (<p>): Menandai awal dari suatu elemen.
  • Atribut (class="info"): Memberikan informasi tambahan tentang elemen. Terdiri dari nama atribut (class) dan nilainya ("info").
  • Konten: Isi teks atau media di dalam elemen.
  • Tag Penutup (</p>): Menandai akhir elemen, diidentifikasi dengan tanda garis miring (/).

3. Struktur Dokumen HTML

Setiap berkas HTML harus memiliki struktur standar berikut agar bisa dibaca dengan benar oleh browser:

<!DOCTYPE html>
<html lang="id">
<head>
    <meta charset="UTF-8">
    <title>Judul Halaman</title>
</head>
<body>
    <!-- Konten website diletakkan di sini -->
</body>
</html>
  • <!DOCTYPE html>: Mendeklarasikan bahwa dokumen ini menggunakan standar HTML5.
  • <html>: Elemen root yang membungkus seluruh konten halaman.
  • <head>: Berisi meta-data penting halaman (seperti charset, title, viewport, link CSS) yang tidak tampil langsung di browser.
  • <body>: Berisi konten visual utama yang akan dilihat oleh pengguna di halaman web.
