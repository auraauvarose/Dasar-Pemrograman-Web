Line Height, Text Indent, & Text Alignment (Materi 10)

📚 Rangkuman Teori

  • Line Height: Mengatur tinggi baris teks (spasi paragraf vertikal).
  • Text Indent: Menjorokkan kalimat pertama paragraf ke dalam.
  • Text Alignment: Perataan teks horizontal (left/right/center/justify).

🛠️ Area Praktik

Paragraf ini memiliki indentasi pada baris pertama. Spasi tinggi baris diatur longgar agar nyaman dibaca.
