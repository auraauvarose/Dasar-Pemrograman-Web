ID, Attribute, & Universal Selector (Materi 03)

📚 Rangkuman Teori

  • ID Selector: Menargetkan satu elemen unik berdasarkan atribut id-nya (diawali tanda #).
  • Attribute Selector: Menargetkan elemen berdasarkan keberadaan atau nilai atributnya.
  • Universal Selector: Menargetkan seluruh elemen di halaman menggunakan tanda bintang (*).

🛠️ Area Praktik

Teks ini menggunakan ID Selector (#special-text).
