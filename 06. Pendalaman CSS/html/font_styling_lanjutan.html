📚 Rangkuman Teori

  • Font Weight: Ketebalan font (bold/normal/nilai numerik).
  • Font Style: Gaya miring (italic).
  • Font Variant: Menghasilkan variasi small-caps.
  • Shorthand: Menggabungkan semua properti font dalam satu properti "font".
